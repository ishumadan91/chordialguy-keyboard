A piano keyboard that reads sargam as well as C D E.

<cg-keyboard> is a web component for music learning apps. It labels keys in Western notes or sargam, limits play to a scale or raag, lights keys in time with a melody, and plays three synthesised instruments with no audio files. 

npm install @chordialguy/keyboard lit

With a bundler

Importing the package registers <cg-keyboard> and <cg-swara>. Lit is a peer dependency, so your app and the keyboard share one copy.

Without one

A single classic script with Lit bundled in. It registers both elements and puts the functions on window.ChordialGuyKeyboard.
